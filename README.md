## Installation
To install SDM, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/sec-zone/sdm.git
   ```
2. Navigate to the project directory:
   ```bash
   cd sdm
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Usage
